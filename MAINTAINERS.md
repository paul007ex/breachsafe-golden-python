## Review and release authority

- Changes to the baseline, workflows, packaging, or release metadata require maintainer review.
- Published artifacts must retain provenance and keyless signing.
- Contributors do not receive package or registry publishing credentials.

## Contributors

Use the repository pull-request process and run the documented quality gates before review.
